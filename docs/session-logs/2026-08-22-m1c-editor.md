## What shipped

### `packages/storage` — the StorageProvider seam made real
- One runnable **contract suite** (`test/contract.ts`) every provider must satisfy:
  empty start · newest-first listing with metadata · byte-identical read · upsert-by-name
  · remove · unknown-id rejection.
- `MemoryStorage` (reference semantics) and `OpfsStorage` — proven against a structural
  fake of the OPFS surface, so the contract runs outside a browser. Real root arrives via
  `openOpfsRoot()` (`navigator.storage.getDirectory()`).
- Scope per OQ-5: recent-files store. Flat, upsert-by-name, nothing else.

### `apps/web` — the first shippable thing
- Vite scaffold; CodeMirror 6 source pane (line numbers, history, markdown language)
- Split view with debounced live preview (150 ms production, 0 in tests)
- Proportional scroll sync (precise AST-position mapping deliberately deferred — v1
  keeps panes aligned by scroll fraction)
- Theme system/light/dark with instant stylesheet swap (`data-theme` + link href)
- Drag-drop and paste ingestion into the store; save/reopen byte-identical
- **Parsing in a module worker** behind the same `MarkdownEngine` interface — the
  workspace cannot tell worker from direct binding (ADR-0002 seam doing its job)

### Engine packaging fix discovered by the build
`loadWebEngine` initially lived beside `loadNodeEngine`; the Node loader's
`node:module` import externalised the entire browser graph. Split into
`wasm-engine.ts` (Node, subpath export `@onemark/engine/node`) and `web-engine.ts`
(browser). All test imports migrated.
